# MvcMovie – ASP.NET MVC Application

ASP.NET MVC application built to practice **Model–View–Controller architecture** and understand separation of concerns in web applications.

## Overview
This project demonstrates a simple web application structured using the MVC pattern, focusing on how data, business logic, and presentation layers interact.

## Technologies
- C# / ASP.NET MVC
- Razor Views
- HTML / CSS
- Basic JavaScript

## Architecture
- **Model** – represents application data and business rules
- **View** – responsible for UI rendering
- **Controller** – handles user input and coordinates communication between Model and View

The project follows a clear separation of responsibilities to improve maintainability and testability.

## Purpose
The main goal of this project was to gain a deeper understanding of application structure and data flow in MVC-based systems.

## QA Perspective
From a QA standpoint, this project helped with:
- Understanding how architectural decisions affect test scope
- Identifying responsibility boundaries when analyzing defects
- Designing more precise test cases based on application layers
- Easier root cause analysis when bugs occur in complex systems
